# Bot Commands List

## Core Commands
- `!help` (DM only) - Provides a menu to access command lists for different systems

## Music Commands
- `!music` - Shows music commands in chat
- `!play <song>` - Plays a song (10 pts, free for VIPs)
- `!dedicate @user <song>` - Dedicates a song (10 pts, free for VIPs)
- `!next` or `!skip` - Votes to skip the current song (free for VIPs)
- `!instskip` - Instantly skips the current song (costs 1000 pts)
- `!stop` - Stops music playback (5 pts, free for VIPs)
- `!clear` - Clears the queue (5 pts/song, free for VIPs)
- `!current` or `!np` - Shows current song info
- `!queue` - Displays the current song queue
- `!autoplay` - Toggles auto-play
- `!mode <type>` - Changes the auto-play mode
- `!modes` - Lists available auto-play modes
- `!stream` - Sends the stream link via DM
- `!lyrics` - Sends the lyrics link via DM

## Economy Commands (DM only)
- `!balance` or `!points` - Check Music Points balance
- `!packs` or `!packages` - View available point packages
- `!costs` or `!prices` - View command costs
- `!givepoints <pts> <user/all>` - (Admin only) Gift points

## Shop Commands (DM only)
- `!buy [item name]` - Search for items (e.g., `!buy tank white`)
- `!buy [number]` - Select an item from search results (e.g., `!buy 1`)
- `!confirm` - Confirm purchase
- `!cancel` - Cancel pending purchase

## Outfit Commands (Admin only)
- `!outfit` or `!outfits` - Show current outfit
- `!wear <preset_name>` - Wear a saved outfit preset
- `!wear <category> <item>` - Wear a specific item
- `!wear <category> 0` - Remove an item from a category
- `!list [category]` - View items in a category (shows owned ✅ and free 🆓)
- `!buy [item_id]` - Buy a specific item (uses the shop system)
- `!outfitlist` or `!presets` - List available outfit presets
- `!clearoutfit` - Remove all worn items
- `!syncoutfit` - Re-sync outfit from Highrise
- `!skin <0-86>` - Change bot's skin color
- `!color <category> <0-255>` - Change item color (hair, eyebrows, facehair)

## Admin Commands (DM only, Admin/Owner only)
- `!addadmin <username>` - Add an admin
- `!removeadmin <username>` - Remove admin status
- `!addvip <username>` - Add a VIP
- `!removevip <username>` - Remove VIP status
- `!admins` - View current admins
- `!vips` - View current VIP list
- `!freemusic <minutes>` - Enable free music mode for everyone
- `!stopfreemusic` - Disable free music mode
- `!admincmd` - Shows a list of admin commands
- `!outfitcmd` - Shows outfit management commands
- `!pstcmd` - Shows position management commands
- `!givepoints <pts> <user/all>` - Give points to users

## System Commands (DM only, Admin/Owner only)
- `!system` or `!info` - View bot system information
- `!version` or `!ver` - Display version details
- `!changelog` or `!updates` - View update history
- `!feedback <message>` - Submit feedback
- `!reportbug <description>` - Report a bug with diagnostics
- `!health` or `!status` - View system health dashboard
- `!ping` - Check bot response time
- `!stats` - View comprehensive bot statistics
- `!btm <command>` - Manage background tasks (owner only)

## Playlist Commands (VIP+ only, DM only)
- `!myplaylist` - List your playlists
- `!playlist create <name>` - Create a playlist
- `!playlist delete <name>` - Delete a playlist
- `!playlist rename <old> <new>` - Rename a playlist
- `!playlist show <name>` - View songs in a playlist
- `!playlist add <playlist> <song>` - Add a song
- `!playlist remove <playlist> <index/query>` - Remove a song
- `!confirmremove <number>` - Confirm song removal after search
- `!playlist play <name>` - Activate a playlist
- `!playlist stop <name>` - Deactivate a playlist
- `!playlist active` - View currently active playlists
- `!playlist info [name]` - View playlist or system info
- `!shufflepl <name>` - Shuffle a playlist
